# MKTG 6620 — AI Business Decisions
## Course repository · Fall 2026

The tools you run: an environment checker, the decision-memo and prompt-log
templates, and the helper scripts that let your code call a coding agent.

```
setup/          install guide, environment checker, choosing a coding agent
templates/      decision memo, prompt log, agent_call helpers
```

### First time

```bash
git clone <this repo>
cd mktg6620-student
python3 setup/check_setup.py
```

Read `setup/S1_setup_guide.md` first — it walks the whole install, Mac and
Windows, and `check_setup.py` tells you whether it worked.

### Where everything else is

**Canvas.** Session handouts, dataset cards, slides, lab scripts, datasets,
assignments, rubrics, quizzes and grades are all posted to each session's
module. This repository does not change during the term, so there is nothing
here to pull.

### Your own work does not go here

You will create your **own** repository for each V&D project — that is what you
submit, and it is where your prompt log, code, and agent transcript live. This
repo is read-only scaffolding; fork or copy from it, never push to it.

### A note on the case

Bonneville Retail Group and its executives are fictional. The datasets are real
and public, and each carries its own licence and attribution in the dataset card
posted with it on Canvas. Findings in this course are findings about those
public datasets, not about any real company.
