# Analytics task instructions — classroom template

This is a task template, not an installed agent configuration or access control.

Read brief.md before calculating. State the decision, observational unit,
period, units, denominator, and permitted transformations. Preserve source
files. Resolve exact repeated IDs using the brief; report conflicting IDs or
missing fields as blockers rather than making up replacements.

Produce audit.json, campaign_summary.csv, segment_summary.csv, analysis.py,
and run_receipt.json in a new work folder. Show counts as well as percentages.
Define net revenue and the revenue-to-spend ratio. Separate observed comparisons
from proposed causal explanations and unknown profit. Do not quietly change
the outcome or population to get a preferred result.

Run analysis.py from a fresh Python process using the unchanged inputs.
Check the consequential totals by a second method. Report the exact command,
input and script hashes, package versions if used, exit status, and output
paths. A success message without saved artifacts is incomplete.

Use only the supplied fictional files. No network, account connections,
package installation, messages, commits, or changes outside the work folder
are part of this task. Enforce these restrictions with the host's actual
permissions when available. Finish with evidence and unresolved questions;
the student or manager makes and writes the business decision.
